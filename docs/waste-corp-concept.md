# Waste Corp — Concept (Sep 2026)

## Fantasy
Player owns a waste / recycling company. Starts with one truck and a small sorting yard; grows into district contracts, a fleet, and factories that turn trash into products.

## Core loop
1. Trucks bring mixed trash
2. Sort into materials: plastic, paper, metal, glass, organic
3. Each material feeds its own factory line
4. Output → money + reputation
5. Reinvest: trucks, workers, lines, contracts

## Company meta
- District contracts (price, reliability, eco score)
- Fleet progression
- Clients (municipality, malls, factories) with different trash mixes
- Reputation unlocks better contracts

## Monetization
Optional ads for boosts; IAP for cosmetics / workers / progress packs; battle pass optional. No ad locks, no gambling core.

## Differentiation
Vs Idle Junkyard (pile idle) and Trash Tycoon Idle (town clean + ads): real waste-company fantasy + sorting into separate material lines.
