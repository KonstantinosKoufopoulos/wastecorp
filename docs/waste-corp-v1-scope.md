# Waste Corp — v1 Scope

## In
1. Sorting yard (player + workers)
2. 3 material lines: plastic, metal, paper
3. One factory per line with speed/capacity upgrades
4. Fleet: 2–3 truck tiers + buy new vehicle
5. Hire/upgrade workers
6. District contracts (3–5 areas): reliability + price
7. Simple reputation
8. Offline progress (limited)
9. Optional ads for boosts; 2–3 IAP packs; 1–2 truck skins
10. First-5-min tutorial + save/settings

## Out (later)
- Glass / organic lines
- Malls / factories as clients
- Night shifts, multiple cities
- Season pass / big live events
- Multiplayer / clubs / leaderboards
- Deep narrative
- Complex eco-score (reputation enough for v1)

## Done means
- Fantasy clear in 5 minutes
- Reason to return tomorrow
- Playable without pay / forced ads
- Feels like a company, not a junk pile clicker
