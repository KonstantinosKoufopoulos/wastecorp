## Full description
Start with one truck and a messy yard. End up running the city’s recycling empire.

Sort mixed trash into plastic, metal, paper, glass, and organics — each feeds its own factory line. Hire workers, upgrade your fleet, and win neighborhood contracts based on speed, price, and eco score.

• Satisfying sorting & factory processing
• Grow from backyard yard to city-wide company
• District contracts, clients, and reputation
• Play offline progress — come back bigger
• Optional boosts & cosmetics — the core game is always playable

Build the waste company the city can’t live without.
