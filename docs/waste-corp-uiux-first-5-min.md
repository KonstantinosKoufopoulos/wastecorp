# Waste Corp — UI/UX notes (first 5 min / v1)

## Principles
- One thing on screen at a time; never two popups
- Hands learn before brain: drag-sort first, text later
- Systems appear only when needed
- No ads, shop, or dark patterns in tutorial

## Yard screen
- Fixed ¾ top-down; yard centered
- Material piles: color + icon (blue plastic, grey metal, brown paper)
- Incoming pile dirtier/higher contrast
- HUD minimal: money | reputation only at start

## Sorting
- Large hit targets; ghost outline near correct pile
- Wrong drop: soft bounce + light shake, no harsh fail UX
- Correct: scale pop + short SFX; juice before numbers

## Machines / workers
- Process once, then on-machine progress bar (no modal)
- Worker visible in yard; readable without labels
- Hire = one card, one CTA, clear price

## Contracts / map
- Simple map overlay; one district highlighted
- Contract card: goal + reward ≤2 lines; one Accept
- Active contract = small persistent chip, not fullscreen

## ~4 min upgrade
- Two equal cards: truck vs yard (forced choice)
- Offline = soft dismissable banner, not blocking popup

## Avoid
- Text walls / Skip before play
- Red bangs everywhere
- Shop from second 0
- Tiny buttons under thumb
- Hiding the loop behind menus in first 5 min

## Visual tone
- Dirty but not gross; chaos → order satisfaction
- Processed materials become neat packs/bales
- Industrial-light UI — not casino gold, not jelly hypercasual
